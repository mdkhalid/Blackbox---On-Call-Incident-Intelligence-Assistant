## Summary
On 2024-11-17, payment-gateway experienced elevated latency and errors due to ERR_CONN_REFUSED. Customers reported checkout failures.

## Impact
Approximately 39% of requests failed for 17 minutes. Revenue impact estimated at $10k.

## Timeline
- 2024-11-17 01:10 - First alert fired for payment-gateway.
- 2024-11-17 01:15 - On-call paged.
- 2024-11-17 01:22 - ERR_CONN_REFUSED observed in logs.
- 2024-11-17 01:35 - Mitigation applied: restarted connection pool.
- 2024-11-17 01:50 - Service recovered.

## Root Cause
The root cause was ERR_CONN_REFUSED in payment-gateway. The connection pool became saturated because upstream dependency slowed down, causing requests to pile up and everything to slow down. No code change to pool sizing; load exceeded configured limits.

## Contributing Factors
- Missing autoscaling for payment-gateway.
- Alert threshold too high.
- Runbook not linked from alert.

## Remediation
Increased pool size and added circuit breaker. Deployed hotfix to payment-gateway.

## Summary
On 2024-09-09, search-service experienced elevated latency and errors due to ERR_RATE_LIMIT. Customers reported checkout failures.

## Impact
Approximately 36% of requests failed for 60 minutes. Revenue impact estimated at $1k.

## Timeline
- 2024-09-09 01:10 - First alert fired for search-service.
- 2024-09-09 01:15 - On-call paged.
- 2024-09-09 01:22 - ERR_RATE_LIMIT observed in logs.
- 2024-09-09 01:35 - Mitigation applied: restarted connection pool.
- 2024-09-09 01:50 - Service recovered.

## Root Cause
The root cause was ERR_RATE_LIMIT in search-service. The connection pool became saturated because upstream inventory-service slowed down, causing requests to pile up and everything to slow down. No code change to pool sizing; load exceeded configured limits.

## Contributing Factors
- Missing autoscaling for search-service.
- Alert threshold too high.
- Runbook not linked from alert.

## Remediation
Increased pool size and added circuit breaker. Deployed hotfix to search-service.

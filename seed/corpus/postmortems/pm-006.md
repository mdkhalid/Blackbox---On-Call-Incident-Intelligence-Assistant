## Summary
On 2024-08-18, user-service experienced elevated latency and errors due to ERR_CACHE_MISS. Customers reported checkout failures.

## Impact
Approximately 8% of requests failed for 29 minutes. Revenue impact estimated at $6k.

## Timeline
- 2024-08-18 01:10 - First alert fired for user-service.
- 2024-08-18 01:15 - On-call paged.
- 2024-08-18 01:22 - ERR_CACHE_MISS observed in logs.
- 2024-08-18 01:35 - Mitigation applied: restarted connection pool.
- 2024-08-18 01:50 - Service recovered.

## Root Cause
The root cause was ERR_CACHE_MISS in user-service. The connection pool became saturated because upstream dependency slowed down, causing requests to pile up and everything to slow down. No code change to pool sizing; load exceeded configured limits.

## Contributing Factors
- Missing autoscaling for user-service.
- Alert threshold too high.
- Runbook not linked from alert.

## Remediation
Increased pool size and added circuit breaker. Deployed hotfix to user-service.

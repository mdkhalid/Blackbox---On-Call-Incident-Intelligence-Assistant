## Summary
On 2024-07-22, order-service experienced elevated latency and errors due to ERR_CONN_REFUSED. Customers reported checkout failures.

## Impact
Approximately 24% of requests failed for 33 minutes. Revenue impact estimated at $34k.

## Timeline
- 2024-07-22 01:10 - First alert fired for order-service.
- 2024-07-22 01:15 - On-call paged.
- 2024-07-22 01:22 - ERR_CONN_REFUSED observed in logs.
- 2024-07-22 01:35 - Mitigation applied: restarted connection pool.
- 2024-07-22 01:50 - Service recovered.

## Root Cause
The root cause was ERR_CONN_REFUSED in order-service. The connection pool became saturated because upstream inventory-service slowed down, causing requests to pile up and everything to slow down. No code change to pool sizing; load exceeded configured limits.

## Contributing Factors
- Missing autoscaling for order-service.
- Alert threshold too high.
- Runbook not linked from alert.

## Remediation
Increased pool size and added circuit breaker. Deployed hotfix to order-service.

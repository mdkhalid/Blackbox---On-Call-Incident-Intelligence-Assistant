## Summary
On 2024-09-01, inventory-service experienced elevated latency and errors due to ERR_AUTH_FAILED. Customers reported checkout failures.

## Impact
Approximately 39% of requests failed for 25 minutes. Revenue impact estimated at $32k.

## Timeline
- 2024-09-01 01:10 - First alert fired for inventory-service.
- 2024-09-01 01:15 - On-call paged.
- 2024-09-01 01:22 - ERR_AUTH_FAILED observed in logs.
- 2024-09-01 01:35 - Mitigation applied: restarted connection pool.
- 2024-09-01 01:50 - Service recovered.

## Root Cause
The root cause was ERR_AUTH_FAILED in inventory-service. The connection pool became saturated because upstream dependency slowed down, causing requests to pile up and everything to slow down. No code change to pool sizing; load exceeded configured limits.

## Contributing Factors
- Missing autoscaling for inventory-service.
- Alert threshold too high.
- Runbook not linked from alert.

## Remediation
Increased pool size and added circuit breaker. Deployed hotfix to inventory-service.

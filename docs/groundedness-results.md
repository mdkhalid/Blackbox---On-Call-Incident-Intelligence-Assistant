## Reading the numbers

- `draft_claim_support` is the honest groundedness number: it counts claims the generator drafted that did **not** trace to a retrieved chunk, before the ground check removed them.
- When the offline deterministic provider is used, generation is extractive from the best-matching evidence sentence, so draft support is expected to be high. Re-run with a hosted model to measure the generator's real overreach; the harness and checker are unchanged.
- Answer-rate failures concentrate in `paraphrase`: the seeded corpus is templated, so those questions carry no distinguishing signal for this retrieval setup (see `docs/retrieval-results.md`). They fail honestly instead of inventing a precedent.
- `abstention_accuracy` is the no-answer path being measured, not merely demonstrated. A system that answers every question fails this row.
